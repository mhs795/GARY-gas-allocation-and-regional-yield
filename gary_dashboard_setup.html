GARY — Gas Allocation and Regional Yield Model

Dashboard Setup, VS Code Only

Everything needed to install, configure and launch the scenario dashboard from inside VS Code — no terminal typing required.

GLPK confirmed installed at /usr/bin/glpsol — no solver install needed

Required packages

Everything below comes from requirements.txt in the project root.

PackagePurpose
pandas, numpydata handling
pyomooptimisation modelling
highspydefault solver backend
plotlycharts
dash, dash-bootstrap-componentsthe dashboard app itself
diskcachebackground callback support in Dash
multiprocessparallel scenario sweeps
zstandardcompresses the results cache (falls back to gzip if missing)
psutilsystem / process info
python-docxWord doc output
openpyxlreads .xlsx parameter workbooks
xlsxwriterwrites .xlsx chart output (openpyxl's chart XML is broken)

GLPK (glpk-utils) isn't in this table because it's a system package, not a pip one — and it's already on this machine, so there's nothing further to install for it.

One-time setup
1
Open the project

File → Open Folder → /home/martinstevenson/models/gas_market_model

2
Select the Python interpreter

Ctrl+Shift+P → Python: Select Interpreter → choose the one under venv/bin/python

3
Install the required packages

Open requirements.txt. The Python extension shows an "Install Requirements" prompt at the top — click it. If nothing appears, the packages are likely already installed — safe to skip.

Running the dashboard with GLPK
4
Open the Run and Debug panel

Ctrl+Shift+D, or click the ▶-with-bug icon in the left sidebar.

5
Pick the config and run

A dropdown at the top of the panel shows "Run GARY dashboard (GLPK)" — already set up in .vscode/launch.json. Select it, then click the green ▶ play button.

{
  "name": "Run GARY dashboard (GLPK)",
  "program": "src/dashboard.py",
  "env": { "GARY_SOLVER": "glpk" }
}
6
Open the dashboard

The Debug Console prints a local URL, typically http://127.0.0.1:8050. Ctrl+click it to open in your browser.

7
Stop it when done

Click the red ■ stop button in the Run and Debug toolbar.
